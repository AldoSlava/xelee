# Button icons

`L.svg`, `R.svg`, `Y.svg` and `Z.svg` are SmashWiki's GameCube button icons
(https://www.ssbwiki.com/Category:Button_icons_(GCN); L by Toomai Glittershine
and others for SmashWiki), available under the Creative Commons
Attribution-ShareAlike 4.0 International license
(https://creativecommons.org/licenses/by-sa/4.0/). They are unmodified.

`tools/gen_button_icons.py` renders them to the 64x64 textures embedded in
`src/pc/button_icons_data.c`; the in-game hints draw those.
